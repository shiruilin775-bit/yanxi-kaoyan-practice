# 研析 · 考研刷题台

一个按考试大纲组织的响应式刷题工具，面向：

- 302 数学（二）
- 101 思想政治理论
- 204 英语（二）重难词与句子翻译
- 南京邮电大学 086100 交通运输专业课：831 运筹学

## 功能

- 全科混合或单科组卷，单套最多 20 题
- 基础、核心、拔高难度筛选
- 所有题目完成后统一展示详解
- 每题附知识点、公式或结构、易错点
- 错题自动收录，并在后续组卷中提高抽取权重
- 翻译题自评、自建题库、90 秒自动换题
- 学习数据保存在浏览器本地，无需账号

## 本地运行

这是一个无构建依赖的静态网站。使用任意静态文件服务器打开 `dist/` 即可，例如：

```bash
python -m http.server 4173 --directory dist
```

然后访问 `http://127.0.0.1:4173/`。

## 大纲口径

南邮 086100 的专业方向与 831 运筹学参考范围依据南京邮电大学研究生招生信息网公开内容整理。题目均为原创训练题，不是真题复刻；形势与政策等时效内容应以当年正式考试大纲为准。
